# Local LLM Tamagotchi App

Built with React, Tailwind CSS, and powered by Ollama: an engaging and interactive pet widget.

## Table of Contents
1. **Features**
2. **Tech Stack**
3. **Getting Started**
4. **Usage**
5. **Contributing**
6. **License**

## 1. Features
- **Virtual Pet**: Customize your own virtual pet with unique personality and generated appearance.
- **Interactive Experience**: Engage with your pet through various actions like eating, playing, sleeping, and chat.
- **Personalized Care**: Receive personalized responses based on your pet's mood, hunger, happiness, and energy levels.


## 2. Tech Stack
- **React**: A JavaScript library for building user interfaces.
- **TailwindCSS**: A utility-first CSS framework for rapidly building custom designs.
- **Ollama**: An open-source language model for generating personalized responses based on your pet's personality and current state.

## 3. Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-repo/local-llm-tamagotchi.git
   cd local-llm-tamagotchi
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the app:**
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 4. Usage
- **Tamagotchi Widget**: A floating widget that displays your pet and allows you to interact with it. You can open or close this widget using the FloatingButton component.
- **Actions**: Perform actions like eating, playing, sleeping, and talking to see how they affect your pet's stats and mood.
- **Chat Interaction**: Engage in a chat with your pet to get personalized responses based on its current state and personality, powered by Ollama.
